# PB4 Respond Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement PB4 so a physical button press can generate a response using active app context plus the user's prior input text.

**Architecture:** Reuse the existing host-to-Pico Raw HID feature request flow and add a new `respond_selection` JSON command on top of `FEATURE_4`. Keep prompt construction on Jetson so the host only sends the prior input text while Jetson reads the active DB session for current app context.

**Tech Stack:** Python, PyQt6, unittest, CircuitPython deployment helper, existing SPARK Raw HID and Jetson bridge code
